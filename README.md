## Featured Project

### WhatsApp AI Lead Agent

An AI-powered system designed to understand incoming WhatsApp enquiries, collect lead information, maintain conversation context, and automatically update business lead records.

The system is being developed to:

- Understand incoming customer messages
- Extract relevant lead information
- Maintain customer conversation context
- Identify missing information
- Ask for only the required information
- Update existing leads instead of creating unnecessary duplicates
- Connect AI processing with business data
- Support automated customer communication

**Technology used in the project:**

JavaScript · Node.js · OpenRouter · WhatsApp · Google Sheets · Google Apps Script · REST APIs · Webhooks · Railway
